# Security Policy

`claude-identity` handles OAuth credentials, so security reports are taken seriously.

## Reporting a vulnerability

Do not open a public issue. Use GitHub private vulnerability reporting:

1. Go to the repository's **Security** tab.
2. Choose **Report a vulnerability** (GitHub Security Advisories).

Include affected versions, platform, reproduction steps, and impact. Never include real tokens.

## Scope

In scope: credential storage and swapping, keyring handling, release artifact integrity, CI/CD workflows. Out of scope: vulnerabilities in Claude Code or Anthropic services themselves.

## Supported versions

Only the latest release receives security fixes while the project is pre-1.0.
